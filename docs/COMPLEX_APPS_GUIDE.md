# Complex Apps Deployment Advice

## ready
Good one-click candidates after basic env/path review.

## starter
Deployable starter. Check `.env.example`, host paths, domain, and app-specific config.

## review
Do not blind-deploy. These may need multiple services, GPU, KVM, privileged mode, DNS planning, or heavy resources.

Review-first examples:
- Dify
- Immich
- RomM
- Langfuse
- MoviePilot-v2
- Virtual DSM
- redroid
- LanCache
- Safeline WAF
- GitLab CE
- vLLM
- SGLang
- OpenClaw / Hermes Agent

Placeholder or external/non-Docker-first service.
