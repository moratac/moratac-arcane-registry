# Arcane Registry v1.0 Official-Compatible

This version mimics the live Arcane community registry format.

## Format

- schema: https://registry.getarcane.app/schema.json
- compose file: compose.yml
- documentation_url: GitHub tree URL
- content_hash: included for each template
