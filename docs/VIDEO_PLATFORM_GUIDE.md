# Video Platform Replacement for Stash

Stash has been removed because it is NSFW-oriented.

General-purpose replacements added:

- Jellyfin: main video/media server
- MediaCMS: private YouTube-style video CMS
- TubeArchivist: YouTube archive with metadata and indexing
- Pinchflat: YouTube channel/playlist downloader for media-server workflows
- Tdarr: distributed transcoding and video library optimization
- Unmanic: simpler video library optimizer/transcoder
- Jellyseerr: request portal for Jellyfin/Sonarr/Radarr
- Overseerr: request portal reference for ARR workflows

Recommended VM: VM102 Media + Downloads + Retro.
